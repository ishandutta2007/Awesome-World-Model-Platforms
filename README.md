# Awesome-World-Model-Platforms
## Top World Model Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Generative World Models, Simulation & Physical AI*  
**Last updated: March 2026**

This repository tracks notable **platforms** and **open-source projects** building **World Models** — advanced AI systems capable of simulating, predicting, and generating dynamic, interactive environments. These models understand physics, enable planning, support robotics, and power generative simulations for video, 3D worlds, and embodied agents.

**Examples** include Google DeepMind (Genie 3), Meta AI (V-JEPA & Codec Avatars), World Labs (Marble), and Generative World Engines (Mirage 2) (the category leaders). Tools listed here emphasize **interactive simulation**, long-horizon prediction, multi-modal understanding, and real-world applicability.

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, local training/inference, customization, and community-driven world simulation — ideal for researchers, robotics teams, and developers building sovereign physical AI systems.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

### Dedicated World Model Projects

- **[V-JEPA 2](https://github.com/facebookresearch/vjepa2)**  
  Meta's open-source video world model with state-of-the-art physical reasoning, prediction, and zero-shot robot control capabilities.

- **[LingBot-World](https://github.com/search?q=LingBot-World)**  
  Fully open-source high-fidelity world simulator with long-horizon consistency, real-time interactivity, and strong dynamics across diverse environments.

- **[Awesome-World-Models](https://github.com/knightnemo/Awesome-World-Models)** (and community forks)  
  Curated collection of world model papers, code, and implementations spanning embodied AI, autonomous driving, and general simulation.

- **[DreamerV3 / Dreamer Series](https://github.com/danijar/dreamerv3)**  
  Leading open-source world model for reinforcement learning and agent training with strong latent imagination capabilities.

- **[Matrix-Game 2.0](https://github.com/search?q=Matrix-Game)**  
  Open-source interactive world foundation model optimized for real-time, streaming simulation and dynamic environments.

- **[OASIS](https://github.com/search?q=OASIS+world+model)**  
  Open implementations of universe-in-a-transformer style world models for high-fidelity interactive generation.

- **[MineWorld](https://github.com/search?q=MineWorld)**  
  Open-source interactive world model built for Minecraft-style environments with real-time dynamics.

- **[GAIA-inspired open models](https://github.com/search?q=GAIA+world+model)** (community reproductions)  
  Open-source adaptations of driving and embodied world models for simulation and planning.

### Additional Strong Open-Source Options

- **DIAMOND** — Diffusion-based world models emphasizing visual details for Atari and simulation.
- **IRIS / iVideoGPT** — Action-conditioned world models for RL agents.
- **HunyuanWorld / Tencent open world models** — High-quality open-source 3D world generation tools.
- **WorldGym** — Frameworks for evaluating policies inside learned world models.
- **PointWorld** — 3D manipulation-focused open world models.
- Many **JEPA-style** and **latent diffusion** implementations for custom world simulation.
- **Awesome lists** and toolkits combining world models with LangGraph / robotics stacks.

**Frameworks for building custom world models**: Combine **V-JEPA 2**, **DreamerV3**, and **LingBot-World** with **PyTorch**, robotics simulators (MuJoCo, Isaac Gym), and agent frameworks (LangGraph, CrewAI) for fully open, interactive physical AI systems.
