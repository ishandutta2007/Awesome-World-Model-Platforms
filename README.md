### 🌐 What are World Models?
World Models are advanced AI systems capable of **simulating, predicting, and generating** dynamic, interactive environments. These systems understand physics, enable strategic planning, and power generative simulations for:
- 🎬 **Video Generation**
- 🎮 **3D Interactive Worlds**
- 🤖 **Embodied Agents & Robotics**
- 🚗 **Autonomous Driving**

## 💻 Open-Source GitHub Projects

### 🛠️ Dedicated World Model Projects

- **[V-JEPA 2](https://github.com/facebookresearch/vjepa2)** 🌟  
  Meta's open-source video world model with state-of-the-art physical reasoning, prediction, and zero-shot robot control.

- **[LingBot-World](https://github.com/search?q=LingBot-World)** 🌍  
  High-fidelity simulator with long-horizon consistency and real-time interactivity.

- **[Awesome-World-Models](https://github.com/knightnemo/Awesome-World-Models)** 📚  
  Curated collection of world model papers, code, and implementations for embodied AI.

- **[DreamerV3 / Dreamer Series](https://github.com/danijar/dreamerv3)** 💭  
  Leading RL world model with strong latent imagination capabilities.

- **[Matrix-Game 2.0](https://github.com/search?q=Matrix-Game)** 🎮  
  Foundation model optimized for real-time, streaming simulation.

### 🧪 Additional Strong Open-Source Options

- 💎 **DIAMOND** — Diffusion-based world models for Atari simulation.
- 🌈 **IRIS / iVideoGPT** — Action-conditioned world models for RL agents.
- 🎨 **HunyuanWorld** — Tencent's high-quality open-source 3D world generation tools.
- 🏋️ **WorldGym** — Framework for evaluating policies inside learned world models.
